# Learning journal

Use this file for chronological notes while building GB-Sec. The aim is to capture what was learned while it is fresh, not to make every entry polished.

## Entry template

### YYYY-MM-DD — Topic

**Goal**

What was I trying to understand or achieve?

**What I did**

Record the experiment, code change, wiring change, reading, or test.

**What I learned**

Explain the concept in your own words.

**Questions / follow-up**

What is still unclear? What should be tested next?

## 2026-10-04 — Project setup

**Goal**

Establish the repository structure and define GB-Sec as both an embedded-systems learning project and a future hardware-security lab.

**What I learned**

A useful engineering record needs to capture reasoning and failed assumptions, not only finished code. The repository is being structured so that firmware, hardware, security analysis, and learning notes remain distinct but connected.
